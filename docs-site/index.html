QueryWeave

Reusable Django ORM reporting toolkit.

Build reports from QuerySets with composable filters, grouping, aggregations, and one-step CSV/JSON exports—without rewriting query logic in every app.

Get Started View on GitHub Install: pip install queryweave

The problem

Django developers repeatedly write and maintain complex ORM query logic for reporting use cases.

  • Filters and lookup logic get duplicated across endpoints and services.
  • Grouping and aggregations are difficult to keep consistent.
  • CSV/JSON exports are often bolted on and hard to test.

The solution

QueryWeave wraps QuerySets in reusable report configurations so your data workflows are declarative and predictable.

  • Define filters, grouping, and aggregations in one place.
  • Reuse report definitions across views, jobs, and APIs.
  • Export report output as CSV or JSON with minimal code.

Features

QuerySet-based reports
Filters (Django lookups)

Quickstart

from queryweave import Report
from shop.models import Order

report = Report(
    queryset=Order.objects.all(),
    filters={"status": "completed"},
    group_by=["category"],
    aggregates={
        "total_sales": "sum(price)",
        "order_count": "count(id)"
    },
    order_by=["-total_sales"]
)

data = report.run()

How it works

  1. 1Pass a Django QuerySet
  2. 2Define filters, grouping, and aggregations
  3. 3Run the report
  4. 4Export results to CSV or JSON
